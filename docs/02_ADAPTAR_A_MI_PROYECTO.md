# Convertir RegistroDemo en mi Trabajo Final

La base NO se entrega como Trabajo Final. Debes cambiar el dominio.

## Ejemplo
- `Registro` -> `Mascota`
- `titulo` -> `nombre`
- `descripcion` -> `raza` / `observaciones`
- `estado` -> `perdida` / `encontrada` / `adoptada`
- `registros_demo` -> `mascotas`

## Orden recomendado
1. Define el problema.
2. Define la entidad principal.
3. Define 3 a 6 campos esenciales.
4. Cambia la tabla.
5. Cambia el modelo Dart.
6. Cambia textos/pantallas.
7. Cambia validaciones.
8. Prueba CRUD.
9. Guarda evidencia.
10. Commit.
